# SWE Mera Challenge

49 issue-resolving tasks (15 php + 16 python + 18 golang)
formatted for [Harbor](https://github.com/laude-institute/harbor). Each task is a real bug from an open-source repository: the agent receives the /testbed directory at the parent commit of the fix along with the issue description, and must ensure that the hidden tests pass.Difficulty: 10 easy, 23 medium, 16 hard.
